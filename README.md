# AI Voice Appointment Agent

A production-style AI receptionist that **answers phone and web calls, understands what the caller needs, answers questions from a knowledge base, and books a tailored meeting on Google Calendar** with an email invite and a Google Meet link.

**Live demo:** `https://<your-app>.vercel.app` · **Call:** `+1 (346) 372-7358`

## Architecture

```
 Caller (phone / browser mic)
        │  audio
        ▼
 ┌──────────────── Vapi ────────────────┐
 │ Deepgram STT → GPT-4.1 → Vapi TTS    │   real-time turn-taking, barge-in, filler speech
 └──────────────────────────────────────┘
        │  webhooks (HTTPS)
        ▼
 ┌──────────── FastAPI on Vercel ───────────────────────────────┐
 │ assistant-request → builds agent config from knowledge base  │
 │ tool-calls        → check_availability / find_open_slots /   │
 │                     book_appointment                         │
 │ knowledge/business.yaml   (services, FAQs, meeting types)    │
 └──────────────────────────────────────────────────────────────┘
        │  HTTPS (Apps Script web app, runs as the calendar owner)
        ▼
 Google Calendar (via Apps Script bridge or Calendar API): busy check + insert (+ Meet link, invites)
```

## What makes it smart

| Capability | How |
|---|---|
| **Knowledge-grounded answers** | `knowledge/business.yaml` (about, hours, FAQs, pricing) is injected into the prompt for each call. The agent may only state facts from the knowledge base. |
| **Understands the caller and adapts** | It picks a **meeting type** (discovery call, technical consultation, demo, kickoff) from what the caller says, then asks that type's **qualifying questions**. |
| **Builds a tailored booking** | Title, duration and **agenda** come from the meeting type. The description includes an AI-written **caller brief** and Q&A, so the team is prepared before the meeting. |
| **Real availability** | Uses Google `freeBusy` and enforces working days, hours, minimum notice and meeting length. Busy, weekend or after-hours requests get the **nearest open slots**. |
| **No double booking** | Re-checks free/busy just before inserting the event. |
| **Time intelligence** | The prompt carries the live local date and time, so "next Tuesday afternoon" works. Other timezones are converted. |
| **Real-world polish** | Confirms details before booking, has the caller spell their email (then validates it), captures caller ID from the phone network, uses filler phrases while tools run, recovers from errors, and hangs up on its own. |
| **Config without code** | Edit the YAML and redeploy. Because the assistant is generated by the backend, prompts aren't duplicated in the Vapi dashboard. |

## Project layout
```
api/index.py            Vercel entrypoint (ASGI)
app/main.py             FastAPI routes: /api/vapi/webhook, /api/assistant, /api/health
app/assistant.py        Generates the Vapi assistant (prompt + tools) from the knowledge base
app/tools.py            Tool handlers: availability, open slots, booking
app/scheduling.py       Pure scheduling logic (unit-tested)
app/calendar.py         Calendar adapters: Apps Script, Google REST (OAuth), in-memory
knowledge/business.yaml Business knowledge base and meeting types
public/index.html       Browser test page (Vapi Web SDK)
tests/                  15 pytest tests (rules, timezones, double-booking, webhook contract)
```

```bash
pip install -r requirements.txt pytest uvicorn

uvicorn app.main:app --reload          # without Google env vars it uses an in-memory calendar
```

## Deploy (free)
1. **Google Calendar (no Cloud project needed):** create a project at https://script.google.com and paste in `google-apps-script/Code.gs`. Optionally add the *Google Calendar API* service to get Meet links. Run `authorize` once, then go to **Deploy → New deployment → Web app** (Execute as: *Me*, Access: *Anyone*) and copy the `/exec` URL.
   *(Alternative: a Google Cloud OAuth client + refresh token via `GOOGLE_CLIENT_ID/SECRET/REFRESH_TOKEN`. Both adapters are in `app/calendar.py`.)*
2. **Vercel:** import this repo and set these environment variables:

   | Variable | Value |
   |---|---|
   | `APPS_SCRIPT_URL` | the `/exec` URL from step 1 (treat it as a secret) |
   | `VAPI_PUBLIC_KEY` | Vapi dashboard → API Keys (public) |
   | `PUBLIC_PHONE_NUMBER` | optional, shown on the demo page |
   | `LLM_MODEL`, `VOICE_ID`, `GOOGLE_CALENDAR_ID` | optional overrides |

3. **Vapi phone number:** Dashboard → Phone Numbers → Free Vapi Number. Leave the assistant empty and set **Server URL** to `https://<your-app>.vercel.app/api/vapi/webhook`. Inbound calls then get the assistant from the backend.
4. Open `/api/health` and check that it shows `"calendar": "google-apps-script"`.
